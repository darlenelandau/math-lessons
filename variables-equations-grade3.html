🔤 Окошко получает имя

В прошлый раз мы решали такие примеры:

(36 : 4) × ☐ − 12 = 60

Сегодня то же самое, только у окошка появляется имя. Чаще всего его зовут x, но имя может быть любым: y, z, a.

(36 : 4) × x − 12 = 60

⚖️ Уравнение: два способа

Равенство это уравновешенные весы
весы уравновешены
сняли по 7 с обеих чаш

Что можно делать с весами, не нарушая равновесия:

1. поменять местами левую и правую части;

2. прибавить к обеим частям одно и то же число или вычесть его;

3. умножить или разделить обе части на одно и то же число, кроме нуля.

Одно уравнение двумя способами. Оба верные, выбирай любой, но проверку делай всегда.

Обратный ход

(x + 7) × 3 = 24
x + 7 = 24 : 3 = 8
x = 8 − 7 = 1
проверка: (1 + 7) × 3 = 24

Весы

(x + 7) × 3 = 24
делим обе части на 3
x + 7 = 8
вычитаем из обеих частей 7
x = 1
проверка: (1 + 7) × 3 = 24

🎯 Сколько решений

Вопрос меняется. Раньше было «найди x», теперь «сколько чисел подходит». Ответов бывает четыре вида: одно число, несколько, бесконечно много и ни одного.

⭐⭐14

Сколько решений у равенства? Если решений немного, выпиши их все.

а)x + 3 = 10
б)x + 0 = x
в)x + 1 = x
г)x × 0 = 0
д)x × 0 = 5
е)2 × x = x + x
ж)x − x = 0
з)x : x = 1
⭐⭐15

Выпиши все натуральные числа, которые подходят.

а)x < 5
б)3 < x < 8
в)x < 20 и x делится на 6
г)10 < x < 20 и x чётное
д)12 < x < 16
е)x не больше 6 и делится на 3

Запись 3 < x < 8 читается так: x больше трёх и меньше восьми.

⭐⭐⭐16

Сколько натуральных чисел подходит? Выписывать не нужно, достаточно сосчитать.

а)2 < x не больше 9
б)7 × x < 100

Во втором пункте назови ещё и самое большое подходящее число.
